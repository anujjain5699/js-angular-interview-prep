## 📁 Repository Structure

The solutions are organized by topic to keep the workspace clean and easy to navigate:

- **`javascript/`**  
  Core JavaScript concepts, custom polyfills, closures, functional programming (currying), object manipulation, and asynchronous concurrency patterns.

- **`angular/`**  
  Angular-specific concepts, component lifecycle hooks, change detection, and RxJS subjects.

- **`html/`**  
  DOM manipulation, UI components, and machine coding tasks (e.g., Autocomplete Search Box with event delegation).

- **`sql/`**  
  SQL interview problems including DDL/DML scripts, window functions (CTEs, `ROW_NUMBER`), and data partitioning.
